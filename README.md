# 📊 Telecom Customer Churn Analysis

An end-to-end Data Analytics and Machine Learning project that predicts customer churn and provides business insights using Python, SQL, SHAP Explainability, Customer Segmentation, and Power BI.

---

## 📌 Project Overview

This project analyzes telecom customer data to identify churn patterns, build predictive machine learning models, explain predictions using SHAP, segment customers, and create an interactive Power BI dashboard for business decision-making.

---

## 🎯 Objectives

- Predict customer churn
- Analyze customer behavior
- Explain model predictions
- Segment customers
- Build an interactive dashboard
- Generate business recommendations

---

## 🛠 Tech Stack

## 📈 Business Insights

- Month-to-Month contracts have the highest churn.
- Electronic Check users are more likely to churn.
- Fiber Optic customers show higher churn.
- Higher monthly charges increase churn risk.
- Customer segmentation supports targeted retention strategies.
